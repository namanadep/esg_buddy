# BRSR Clauses Reference Guide

This document lists all BRSR (Business Responsibility & Sustainability Report) clauses that are evaluated in the ESGBuddy application.

**Total Clauses:** 265 (as shown in your reports)

---

## How BRSR Clauses Are Organized

BRSR framework consists of:
1. **BRSR Core** - 9 standardized ESG metrics (mandatory for top 1000 companies)
2. **Section A** - General Disclosures
3. **Section B** - Management and Process Disclosures  
4. **Section C** - Principle-wise Performance Disclosure (9 Principles)

Each principle in Section C has:
- **Essential Indicators** (mandatory)
- **Leadership Indicators** (voluntary)

- **Clause ID:** `BRSR_Core_3_*`

## How to Use This Reference

### For Ground Truth Creation:
1. Pick a clause ID from above (e.g., `BRSR_P6_EI_3` for GHG emissions)
2. Open the company PDF (TCS, RIL, or TATA Motors)
3. Search for the disclosure (e.g., Scope 1, 2, 3 emissions data)
4. Determine:
   - **Status:** supported / partial / inferred / not_supported
   - **Pages:** Which pages contain the evidence
   - **Notes:** Why you chose that label
